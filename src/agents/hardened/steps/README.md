# Hardened steps

This directory should contain one folder per hardening step.

Suggested examples:

- `01_remote_mcp`
- `02_domain_separation`
- `03_identity_and_secrets`
- `04_authorization`
- `05_human_approval`
- `06_tool_allowlists`
- `07_guardrails`
- `08_observability`

Each step should include its own configuration, validation check, and documented security rationale.
